### Инициализация проекта
```
Создать новый репозиторий в текущей папке:

git init

Клонировать существующий репозиторий:
git clone ...
```
### Основной цикл работы
```
git status              # посмотреть состояние файлов
### Отправить изменения
git push
```

### Получить изменения
```
git fetch
```
